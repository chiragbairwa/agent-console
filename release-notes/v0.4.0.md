Agent Console 0.4.0 adds the **reviewer seat**: a second, read-only advisor that gives the lead a second opinion.

## Downloads

| File | System | What it is |
|---|---|---|
| `agent-console_0.4.0_amd64.deb` | Debian, Ubuntu (x64) | The CLI and the desktop app. Install with `sudo apt install ./agent-console_0.4.0_amd64.deb`. |
| `AgentConsole-0.4.0-x86_64.AppImage` | Linux (x64) | The desktop app with the CLI inside. `chmod +x` the file, then run it. |
| `AgentConsole-0.4.0-macos-arm64.*` | macOS (Apple silicon) | The desktop app. |

## New

- **Reviewer seat.** Add it in the advisor `⋯` menu with **Add Reviewer…**. It is off by default. API: `POST /api/reviewer {"agent":"codex"}`, and `POST /api/reviewer/remove`.
- **Second opinion.** The lead calls `ask_second_opinion`. The reviewer answers with `advise`. The answer arrives at the lead as `[from Reviewer] …`.
- **Read-only tools.** The reviewer has `list_workers`, `read_worker` and `advise`. It can read any box, but it has no tool that changes a worker or a link.
- **One link.** The reviewer has a link to the lead only, not to a worker.
- **Direct message.** Type `@reviewer text` to write to the reviewer. Plain text goes to the lead.
- **Swap Roles.** This menu item swaps the agents of the lead and the reviewer seats. Each seat resumes its own session. API: `POST /api/reviewer/swap-roles`.
- **Packages.** The release now has a `.deb`, an AppImage, a macOS app with its icon, and a Windows app.

## Fixes

- A seat cannot be removed while an advisor swap runs. A reviewer remove waits for the running swap.
- The seat ids `advisor` and `reviewer` are reserved for the seats. The seat checks use the role, not the name.
- When you cut the link between the lead and the reviewer, the reviewer messages stop. The link does not stay after the reviewer is removed.
- When you remove the advisor, the links to its workers that you cut stay cut.

## Known limits

- The read-only rule of the reviewer is a cooperative rule that the console tools enforce. It is not a security boundary: all sessions run as the same user, and Codex runs without a sandbox.
- The files are not signed. On macOS, right-click the app and click **Open** the first time. On Windows, SmartScreen can show a warning: click **More info**, then **Run anyway**.
- Not tested on macOS yet. If a step fails, open an issue with the output of `agent-console doctor`.
