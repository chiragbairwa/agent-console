Agent Console 0.5.1 is a fix release. The console now finds `claude` and `tmux` when it starts from the app menu or the Dock, and a session that cannot start shows the reason on its card.

## Downloads

| File | System | What it is |
|---|---|---|
| `agent-console_0.5.1_amd64.deb` | Debian, Ubuntu (x64) | The CLI and the desktop app. Install with `sudo apt install ./agent-console_0.5.1_amd64.deb`. |

## Fixes

- **Claude is found after a launcher start.** A start from the app menu or the Dock does not read the shell profile. The server now adds the `PATH` of your login shell (nvm, fnm, volta, asdf, npm prefix) before it starts a session. `agent-console doctor` uses the same `PATH`.
- **Homebrew on macOS.** A Dock start gets only the system `PATH`. The console now adds `/opt/homebrew/bin`, `/opt/homebrew/sbin` and `/usr/local/bin` at the end, so it finds Homebrew `tmux`.
- **Local sessions get the server PATH.** A tmux server from an older start keeps its old `PATH`. Each new local session now gets the `PATH` of the server.
- **A failed start is visible.** When the agent is not on `PATH`, when its folder cannot be read, or when the session ends at once, the card is stopped and shows the reason. Activity gets one line. A green "Restarted" no longer hides the problem. This applies to a new worker, a restart, the Advisor, and Move into Console.
- **Blocked folder on macOS.** macOS protects Desktop, Documents and Downloads. The card now tells you to give Agent Console access in System Settings → Privacy & Security → Files and Folders (or Full Disk Access). On macOS, `agent-console doctor` warns about a blocked folder in `roots` or `advisorCwd`.
- **Resume of a session with no messages.** A session that never got a message has no transcript, so `claude --resume` failed. A restart now starts fresh in that case. The check uses `CLAUDE_CONFIG_DIR` and looks in all Claude project folders.
- **A new worker is known at once.** A new worker is registered before its session starts. Its tools, hooks and first prompt are not lost while the console checks the start.
- **Drop a file on a terminal.** A file that you drop on a box or the focus terminal pastes its path, as in a real terminal. The page no longer opens the file. The file content is never uploaded.
- **Doctor and a running console.** When the console runs, `agent-console doctor` shows `✓ port 7878 used by the running Agent Console`, not a failure.
- **Doctor port.** `agent-console doctor` now checks the port from `AC_PORT` or the config, not always 7878.

## Known limits

- The desktop app is not signed. On macOS, after you copy it to Applications, run `xattr -dr com.apple.quarantine "/Applications/Agent Console.app"` one time. On Windows, SmartScreen can show a warning: click **More info**, then **Run anyway**.
- `agent-console doctor` that you run from Terminal uses the permissions of Terminal. It can say that a folder is readable while the app is blocked.
- A remote session gets no start check. The host poll finds a session that ended.
