Agent Console 0.5.0 adds **remote hosts**: run workers on other machines over SSH, and see them on the same canvas.

## Downloads

| File | System | What it is |
|---|---|---|
| `agent-console_0.5.0_amd64.deb` | Debian, Ubuntu (x64) | The CLI and the desktop app. Install with `sudo apt install ./agent-console_0.5.0_amd64.deb`. |
| `AgentConsole-0.5.0-x86_64.AppImage` | Linux (x64) | The desktop app with the CLI inside. `chmod +x` the file, then run it. |
| `AgentConsole-0.5.0-macos-arm64.*` | macOS (Apple silicon) | The desktop app. |
| `AgentConsole-0.5.0-windows-x64-Setup.*` | Windows (x64) | The desktop app. |
| `agent-console-<os>-<arch>.tar.gz` / `.zip` | Linux, macOS, Windows | The CLI only. Put `agent-console` on your `PATH`. |
| `SHA256SUMS` | all | The SHA-256 checksums of all files. |

## New

- **Remote hosts.** Click **Hosts**, then **+ Add Host**, or import `~/.ssh/config`. The login uses `ssh-agent` or a key file. The console stores no password.
- **Remote workers.** A worker runs in tmux on the host. Its hooks and tools reach the console through a reverse tunnel. Each host has a **Tunnel port**.
- **Group by Host.** One toolbar button puts the boxes in one lane for each host.
- **Send to Host.** Move the work of a worker to another host: the branch bundle, the uncommitted changes of tracked files, the brief and an optional extra folder.
- **Shell box.** **Open Shell** opens a plain login shell on a host. Only you can type into it. Agents cannot read it, type into it or link to it.
- **Host doctor.** `agent-console doctor --host <id>` checks one host over SSH.

## Fixes

- A shell box refuses input from any sender but you, also inside the console.
- **Open Shell** is disabled while its request runs. A running dialog is not closed by a second dialog.

## Known limits

- Untracked files are not sent by Send to Host.
- The Extra folder needs `rsync` 3.0 or newer on the host. On macOS, run `brew install rsync`.
- When the keychain is locked over SSH, run `claude setup-token` on the host and set `CLAUDE_CODE_OAUTH_TOKEN`.
- A Mac host must not sleep: `sudo pmset -a sleep 0`.
- Not a sandbox: all sessions on a host run as the same user.
- The files are not signed. On macOS, right-click the app and click **Open** the first time. On Windows, SmartScreen can show a warning: click **More info**, then **Run anyway**.
