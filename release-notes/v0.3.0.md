Agent Console 0.3.0 is the first public release. Agent Console is a local web canvas for Claude Code and Codex. Each box is a live terminal that runs in tmux. One **advisor** session sends work to the **worker** sessions and watches them.

## Downloads

| File | System | What it is |
|---|---|---|

## Features

- **Canvas of live terminals.** Each box runs `claude` or `codex` in tmux. The work continues when you close the window or stop the server.
- **Advisor and workers.** One advisor session is the single point of contact. It starts workers, sends them work, and decides which workers may talk to each other.
- **Switch the advisor agent.** Click `Advisor: <agent> ▾` in the top bar to switch the advisor between Claude and Codex. Each agent keeps its own conversation.
- **Codex workers.** In Add Worker, set **Agent** to Codex. You can set a model and a reasoning level.
- **Guard for risky commands.** Push, deploy, pipeline-run and gate-approval commands wait for your **Allow** or **Deny** in the console.
- **Status digest.** Every few minutes the advisor gets one line for each worker that changed: state, step, time in the step, and what it waits on.
- **Resizable boxes**, a Flow view with the plan steps of each worker, and links to outside Claude Code sessions.
- **Desktop app.** A native window with a tray icon. It starts the console server when the server does not run.

## Requirements

- tmux, and Claude Code installed and logged in. Codex is optional.
- Linux desktop app: WebKitGTK 4.1, GTK 3 and Ayatana AppIndicator. The `.deb` installs them.
- Windows: the sessions need tmux. Run the Linux CLI in WSL.

## Known limits

- The files are not signed. On macOS, right-click the app and click **Open** the first time. On Windows, SmartScreen can show a warning: click **More info**, then **Run anyway**.
- Not tested on macOS yet. If a step fails, open an issue with the output of `agent-console doctor`.
- The guard is a regex on the command text. A push through an alias or a script is not caught.
